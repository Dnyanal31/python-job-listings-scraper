# Python Job Listings Scraper

## Project Description
This project is a beginner-friendly Python web scraper that collects job listings from the Fake Python Jobs website.

The scraper extracts job titles, company names, locations, and job URLs and saves the collected information into a CSV file.

## Project URL
https://realpython.github.io/fake-jobs/

## Technologies Used
- Python
- Requests
- BeautifulSoup
- CSV

## Features
- Collects job titles
- Collects company names
- Collects locations
- Collects job URLs
- Saves data into a CSV file

## Output
The scraped job information is stored in `job_listings.csv`.

## How to Run
1. Install the required libraries:
   `pip install requests beautifulsoup4`
2. Run the Python file:
   `python main.py`
3. The collected data will be saved in `job_listings.csv`.
